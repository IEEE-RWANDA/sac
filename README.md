# IEEE SAC Rwanda

Static local prototype adapted from the IEEE Region 8 SAC site structure. Run `npm run dev` and open http://127.0.0.1:4187. JavaScript syntax: `npm run check`.

Includes manual hero carousel, mission, regional announcements, branch directory placeholder, awards, official branch resources, funding programme links, committee/contact placeholders, and a browser-local activity planner.

Before publication: confirm Rwanda mission, committee, branch directory, contacts and events; replace reference photography with approved Rwanda assets; review IEEE branding. No authentication or shared submissions are implemented.

Reference: https://r8.ieee.org/sac/ and its Resources, Recognition and Support pages, read through the signed-in Codex browser. Regional links are labelled as regional. Hero/news photographs are locally saved reference assets from the Region 8 page and are credited on the site; they are not represented as Rwanda event photos. Montserrat is locally hosted from the reference site's observed font asset.
